# apps/

Each directory is an app entry point (`apps/<app>/`) that wires `riso/` components and `crate/`
components into a running application.

Start `main` with `riso_identity::init(...)` and then `riso_log::init()`; do not call
`zlog::init()` (see "Logging" in the root `AGENTS.md`).

`apps/ide` is a mirror of Zed generated by `cargo neutron sync`. It exists only to prove that `core/`
and the shims still build the full Zed; do not develop features there and do not depend on its crates.
