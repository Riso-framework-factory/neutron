# 0005. No CI for now; only the upstream sync workflow

Status: accepted (2026-10-24)

## Decision
The only GitHub workflow is `upstream-sync.yml`. It runs `cargo neutron verify` (static checks, no
compilation) and can optionally run `cargo check` when `NEUTRON_SYNC_COMPILE_CHECK=true`.
Sync PRs are never auto-merged: a maintainer runs `cargo neutron doctor` locally and merges by hand.

## Consequences
- The workflow uses the default `GITHUB_TOKEN`; no GitHub App is needed until other workflows must
  run on sync PRs.
- Breakage is found later than with CI; `verify` and `doctor` are the safety net.
